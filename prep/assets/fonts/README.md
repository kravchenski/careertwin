# Fonts

Three open fonts (SIL Open Font License 1.1, see the `OFL-*.txt` files), cut down to Latin and
Cyrillic so the program stays small:

- **PT Serif** (Regular, Italic, Bold): titles.
- **Manrope** (Regular, SemiBold, ExtraBold): text and buttons. The upstream file is a variable
  font; these are static instances at weights 400, 600 and 800.
- **JetBrains Mono** (Regular, SemiBold): small capital labels, timers and numbers. Static
  instances at weights 400 and 600 of the upstream variable font.

Sources: <https://github.com/google/fonts> (`ofl/ptserif`, `ofl/manrope`, `ofl/jetbrainsmono`).
